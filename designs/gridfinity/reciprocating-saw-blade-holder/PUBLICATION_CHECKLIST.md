- [ ] Confirm the derivative license in `LICENSE.md` is compatible with the upstream license.

- [x] No repository-wide license applied to unrelated future designs.
- [ ] Confirm you're publishing this remix **noncommercially**; selling models/prints or otherwise commercializing it would need extra permission.
- [ ] Run `python scripts/check_meshes.py` from this design folder.
- [ ] Preview both STLs in QIDI Studio, note any generated supports.
- [ ] Physically check Gridfinity fit, cover sliding, and latch retention.
- [ ] Save finished print photos and any validated slicer `.3mf` in the project.
- [ ] Review files and images for personal identifying information before publication.
